## 目录约定

每门课程位于 `courses/<topic>/`：

- `MISSION.md`：学习目标
- `RESOURCES.md`：权威资料
- `NOTES.md`：教学偏好与工作笔记
- `lessons/`：互动 HTML 课程
- `reference/`：长期参考资料
- `learning-records/`：已验证的学习记录
- `assets/`：课程共享组件
